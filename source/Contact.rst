联系与支持
==========

技术支持入口
------------

* `CubeBraid 官方网站 <https://www.cubebraid.com/>`__
* `CubeBraid SDK 源码仓库 <https://github.com/GJXS1980/cubebraid_sdk>`__
* `文档仓库 Issues <https://github.com/zjx99999/cubebraid_documentation/issues>`__

提交问题时请提供：

* SDK commit、文档版本和操作系统/编译器；
* 使用的模块、头文件和 DLL 名称；
* 完整的错误码、日志和最小复现步骤；
* 设备型号、网络拓扑和端口（不要提交密码、密码哈希或生产网络凭据）；
* 是否可以稳定复现，以及是否只在真实设备上出现。

安全问题
--------

不要在公开 issue 中上传真实 IP 清单、登录凭据、PLC 配方、客户数据或生产日志。涉及设备安全、远程控制或凭据泄露的问题，请通过官方支持渠道私下提交。
