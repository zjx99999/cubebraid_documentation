5.5 安全与故障排查
===================

本页说明 RS080N/R2C 的现场操作要求和常见故障；通用要求见 :doc:`安全须知 <../Guides/Safety>`。

真实设备边界
------------

* Python 真实配置即使 ``dry_run: true``，也会在 ``connect()`` 时访问控制器并读取反馈；只有显式选择 ``mock`` 才是本章的离线验证方式。
* C++ 关节示例连接后执行 12 个关节动作；位姿示例在预览模式下连接控制器并读取实际位姿。
* CubeBraid Python 驱动的 ``stop()`` 返回 ``False``。现场急停与安全回路须独立于软件超时、通信状态和进程运行状态。
* 首次运动前必须由现场负责人确认急停、限位、工作空间、人员隔离、轴序、坐标系和目标单位。失败后禁止自动重试运动。

常见问题
--------

``check_environment.py`` 导入失败
   确认已激活 ``rs080n_r2c`` 环境，并从运行时根目录安装 ``packages/r2c_sdk_python``；RS080N 插件需另行安装。

插件无法发现或导入
   核对 ``RS080N_R2C_Plugin_v1`` 已安装到同一 Python 环境，且 ``pyproject.toml`` 的 ``r2c_sdk.adapters`` 入口可被 R2C SDK 识别。

CubeBraid 动态库加载失败
   核对系统架构、Python/C++ 位数以及随工程提供的运行时库版本。

连接或初始反馈失败
   核对现场网络、控制器状态及端口；检查反馈是否有效、轴序是否经确认。初始反馈无效时，驱动返回连接失败；修复反馈后再继续联调。

动作被拒绝或到位超时
   核对关节限位、最大单步变化、控制模式、反馈容差和故障状态。
   ``sent`` 仅表示命令已发出；超时后先确认机器人实际位置，再决定后续动作。

CloudRobo 无法上线
   先完成本地插件的导入与适配器验证，再核对平台签发的凭据包路径、``--robot-config`` 指向的配置文件、证书密码及平台网络连接。
