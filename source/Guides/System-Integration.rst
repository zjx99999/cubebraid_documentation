4.2 系统联调与异常处理
========================

系统联调过程中，各模块间需建立完善的联动防护机制。

通信断线保护
------------

当底层检测到 AGV、Robot 或 PLC 网络中断，或 Inclinometer 串口中断时，应触发项目定义的自动重连或安全停止流程，并通知机械臂暂停运动。自动重连不能替代现场急停与安全回路。

位姿安全性校验
--------------

视觉与倾角仪计算出的位姿在下发给机械臂前，必须经过 ``KinematicsSolver`` 的奇异点检测和安全边界校验。还应结合控制器的关节限位、工具姿态、碰撞区和安全速度确认动作可执行。

异常处置
--------

任一模块返回失败、超时或状态不一致时，应停止后续动作，记录模块、函数、参数摘要、返回值和设备状态；在人工确认后决定重试、回退或结束任务。
