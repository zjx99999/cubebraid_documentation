安全须知
========

CubeBraid SDK 可以通过网络、串口和 PLC 信号驱动真实设备。本文档中的示例只说明接口用法，不构成机械安全设计、风险评估、功能安全回路或现场作业规程。

首次联调
--------

#. 先在断开执行机构、低风险工装或仿真环境中运行参数读取和纯算法接口。
#. 逐一核对 AGV、机器人、PLC、相机和倾角仪的 IP、端口、串口、坐标系和单位。
#. 确认急停、限位、防护门、碰撞检测和人工接管方式可用。
#. 首次发送运动指令时使用项目批准的安全速度、距离和姿态，并安排现场人员监护。
#. 检查设备反馈后再执行下一步，不要用固定 ``sleep`` 代替状态确认。

高风险接口
----------

以下接口可能直接影响设备：

* ``AGVController::goForward``、``goBack`` 和手动速度接口；
* ``RobotController::controlPosture``、``controlJoint``；
* ``PLCController`` 的吸盘、底托、摆台和初始化信号；
* 对应 C ABI 的 ``AGV_*``、``Robot_*`` 和 ``plc_*`` 函数。

``moveManualForDuration`` 和 Python ``move_manual_for_duration`` 会在结束时发送速度归零指令，但应用仍必须处理通信中断、急停和控制器异常，不能把“自动归零”当成唯一的安全措施。

凭据与网络
----------

AGV 登录接口接收密码哈希字符串。示例中的用户名、IP 和哈希仅用于说明格式，不得直接用于生产；凭据应由安全的配置管理系统提供，并避免写入日志或 Git。

异常处理
--------

任何连接、登录、运动、PLC 写入或视觉算法失败，都应：

* 停止发送新的动作指令；
* 按项目状态机执行可验证的安全停止；
* 记录模块、函数、参数摘要、返回值和设备状态；
* 在人工确认后决定重试、回退或结束任务。

坐标与单位
----------

RobotSDK 使用 mm/deg 的机器人目标数据，而 CameraSDK 的标定和基准点示例使用 m。错误的单位换算可能导致严重运动风险；请在每次跨模块传递前显式转换并记录单位。
